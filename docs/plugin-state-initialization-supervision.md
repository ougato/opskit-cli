# 插件状态父目录初始化监督

调用入口此前在主进程对self或caller分区执行mkdir(parents=True)。这发生在容器创建之前，但不受一次性worker期限约束；慢磁盘上的mkdir可能阻塞取消。

现在调用入口把initialize选项交给已有恢复worker，worker先初始化父目录，再持事务锁执行恢复。没有增加worker或保留第二条入口创建路径；默认恢复及提交后清理不创建父目录。

初始化只能接受平台data_dir下plugin-data/目标插件/self（platform调用）或callers/已绑定调用方。逐层检查普通目录并创建缺失父目录，拒绝链接、reparse点、特殊对象及不规范父路径；只创建父目录，不创建或发布状态根。已存在链接在向其内部创建目录前拒绝。此处不承诺抵御已控制宿主账户的并发目录替换，也不提供断电持久性保证。

阻塞mkdir由现有恢复期限和父生存期监督；超时或取消确认worker退出后可重试。若中途创建过空父目录，允许保留，不按名字删除。sandbox临时工作目录、请求写入及其他宿主I/O仍需继续处理，不能由本改动推导整次invoke已受监督。
