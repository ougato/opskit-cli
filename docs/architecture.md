# OpsKit 架构

OpsKit CLI 提供软件、监控、网络及通用插件框架。官方模块由注册表装配；第三方插件通过清单、内容信任、不可变运行时和原生沙盒执行，宿主不导入第三方 Python 代码。

## 插件执行链

清单 SDK 版本检查 → 内容审核/信任 → 依赖准备及 SDK 摘要核验 → Windows AppContainer worker → 有限 RPC → 宿主 broker。SDK 4 与 RPC 传输版本独立。旧 SDK 1/2/3 不进入插件管理列表；升级后须重新安装并准备运行时，旧目录和数据不会自动删除。

Windows 使用 AppContainer、Job Object、期限、进程树回收和工作区归属记录；Linux/macOS 后端尚未实现，明确拒绝。插件执行不使用 Docker/WSL，也不降级为普通宿主 Python。

## 宿主能力

SDK 提供目录读取、文件摘要、受限 HTTPS、上传、通用工具执行及产物凭据。每项能力由 broker 验证参数、插件身份、授权范围、期限和撤权。宿主工具使用独立参数数组，不经 shell，按用户权限运行；工具可能执行工程脚本，该边界须展示给授权人。

执行与产物操作共享资源锁。工具原始退出码由插件解释；宿主新建独立输出、核验身份与内容，按插件登记凭据。未知、变化、跨插件、活动目录均不能通过凭据清理。

## 状态与维护

插件管理包含安装、更新、卸载、权限与维护。维护包含更新回滚、沙盒清理、临时清理、缓存清理和空间设置。清理须依赖归属记录和摘要，不能扫描后直接删除未知目录。

最低剩余空间默认 2048MiB，可配置 256..1048576MiB；这是预检查和运行中检查，不是磁盘硬配额。旧业务配置字段仍保存，但读取通用阈值不依赖它们是否合法。

## 业务边界

特定编辑器配置、参数、成功码、平台产物规则、构建历史交互和保留策略属于独立业务插件。Cocos 源码位于独立 `plugin/cocos` 项目，内部仅使用公开 SDK。框架不加载该插件业务代码，也不自动安装或授信。

接口细节见 [插件规范](plugin-spec.md)，升级及旧数据保护见 [业务分离与迁移](sdk3-business-separation.md)。


## 插件仓库认证

安装和更新直接开始采集，不预先选择公网／内网或匿名／认证模式。安装菜单中用户亲自提交地址允许本次连接该主机和端口的私网或保留地址；更新已有来源遇到私网时仍须本次明确确认，命令行使用显式 `--allow-private`。下载后展示插件版本、权限与指纹并请求信任，拒绝时回滚安装，不自动授信。

SSH 在专用传输进程内只读取当前用户 `.ssh/known_hosts` 中准确主机及端口的记录；验证服务器密钥后，最多尝试八个代理密钥和默认 `id_ed25519`、`id_ecdsa`、`id_rsa` 私钥，私钥保留权限检查。不会执行 SSH 配置、ProxyCommand 或任意 Git helper。未知或变化的服务器密钥不自动接受；认证不可用时，交互界面请求绑定仓库的显式凭据文件。自定义 IdentityFile、尚未解锁的加密私钥等需通过代理或显式凭据使用。

HTTPS 首先匿名请求，收到 401／403 后可读取 Windows 凭据管理器中同一 HTTPS 地址的 Git 凭据，优先仓库路径、再精确服务器；不运行 helper，不自动跳转，不关闭 TLS 验证。没有可用凭据或认证仍被拒绝时，交互界面请求显式凭据文件。凭据不进入插件或隔离 Git 工具，不写入安装记录；不声明兼容所有宿主 Git 认证配置。

每种异常最多交互一次，重试共享原有总期限。非交互调用不会弹出确认。原有独立 pack 校验、隔离解析和信任检查继续执行。


## 安装自动准备

Windows x64 的菜单和命令行安装使用同一自动准备链路。准备采集工具后才报告正在克隆，候选通过来源/内容审核后准备指纹绑定的运行环境，工具与运行时校验通过才发布插件目录。菜单原有版本/权限/信任确认继续执行，拒绝或取消时按安装凭据回滚；命令行保留独立显式授信。调用跨插件服务不会自动安装提供方。

采集工具优先发现本机 CPython 3.10+ Windows x64 与 Git 安装并复制必要文件，在 AppContainer 中验证后复用；不修改本机工具、不执行宿主包装脚本。插件执行运行时单独使用 SDK 所需的 CPython 3.14 Windows x64 ABI。仅缺失、不兼容或自检失败的组件需要补齐。固定输入见 `core/plugin-bootstrap.json`：Python Windows 嵌入式发行、MinGit 与 SDK wheel 均锁定 URL、大小和 SHA256，下载跳转仅限 HTTPS 官方分发域名，缓存每次核验。来源由 Python 官方发布的 Sigstore 摘要、Git for Windows 发行页校验表及 PyPI 文件元数据核对；不在运行时采用 latest 或联网解析插件依赖。首次准备只在安装时触发，帮助/列表等只读入口不会下载或初始化工具。平台之外不降级到宿主执行。

基础 SDK 依赖自动准备；自定义业务依赖继续走审核过的离线输入，不读取仓库安装脚本。准备失败不会发布插件，已验证工具与下载缓存可在重试时复用，未知或损坏记录不被自动清理。
