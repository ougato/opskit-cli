# 插件运行时管理

插件的执行环境由框架统一检查和维护。插件无需实现 SDK 更新、下载或替换逻辑；其内容和已准备的依赖仍由现有安装、审核及授权流程管理。

框架在执行前校验插件身份、运行时清单和所有文件。当插件内容一致、运行时完整，但框架 SDK 摘要变化时，管理器选择 SDK 更新策略：从已验证的旧运行时创建副本，仅替换框架 SDK，保留原 Python、依赖文件及依赖锁记录；复核授权、SDK 和旧运行时指针后原子发布，并重新校验后执行。菜单预加载不执行更新，用户选择插件后才处理。

缺失、损坏或插件内容不匹配不会按 SDK 更新处理，也不会自动替换为基础依赖。插件授信、权限和用户数据不因运行时更新而改变。将来增加其他更新类型时，由框架定义明确的检查结果和对应策略；不能直接把插件声明当作执行更新或授予权限的依据。
