# 发布与更新校验

发布由 GitHub 的 `v*` 标签推送触发，无需配置发布公钥或私钥

四个平台分别生成二进制、SHA256 文件和用于流水线核对的 manifest.json
发布前校验版本、平台、架构、文件大小和摘要，公开二进制与 SHA256 共八个文件
发布使用草稿事务，核对全部远端资产后才公开，重试只补缺失文件
公开版本及已有标签不覆盖，修复后使用新版本标签

安装脚本先验证 SHA256 再安装，不依赖 OpenSSL
自动更新通过 HTTPS 和既有仓库策略选择产物，要求有效 SHA256
下载在私有候选目录完成，写入包含版本和摘要的 candidate.json 后原子发布缓存指针
应用及启动重试时重新核对候选版本、摘要、目标身份和事务状态
保留超时、取消、配额、链接检查、回滚和健康确认
SHA256 用于检查内容完整性，不提供独立发布者身份认证

插件授信、宿主权限、SSH 身份校验及依赖锁定继续按各自规范执行

## 回滚退役边界补充（2026-10-13）

已索引schema2回滚任务只在helper精确身份确认退出、实际目标摘要已恢复、反向事务及备份/健康归属一致后退役。先在job.json持久化完整退役凭据，再将匹配活动索引转为last_apply_job历史；中断可重试，不清除其他任务索引。删除载荷失败时所有权记录保留，未知文件和历史/健康/marker引用不清理。

目标记录持久化upgrade_floor，后续升级必须高于最高回滚build；后来准备失败或中止不能解除下限。仅证明已索引现代回滚任务路径，未索引/旧任务、其他终态及未提交回滚启动恢复仍待实现/验收。本地故障注入和真实PowerShell临时产物不替代真实断电或跨平台发布。

## 插件构建客户端监督（2026-10-13）

镜像查询和构建不再使用直接subprocess.run/check_output；统一有界输出及本地进程树监督。公开终端仅显示固定进度，Docker/pip日志不直出。查询阶段30秒/4KiB，构建客户端600秒/4MiB；超时、取消或输出超量关闭本地进程树，最终镜像验证前不发布新catalog。真实临时Python客户端及子进程验证了超时/注入取消/超量回收、文件stdin准确性和凭据不入终端。

此证据不覆盖Docker daemon内部构建取消、BuildKit缓存回收、prepare总期限、来源镜像digest及全部传递依赖hash。Docker API在相关单测中由替身提供；没有运行用户插件或实际镜像构建，不因此宣称真实沙箱或供应链达标。

## 完整wheel锁与来源digest策略（2026-10-13）

prepare要求操作方提供registry digest及完整锁，标签/缺锁/无SHA256条目/未知选项/URL/递归include拒绝。文件有界且不跟随链接；版本与所有wheel哈希规范化，--dependency仅核对锁，不追加任意包。pip isolated、ignore-installed、require-hashes、only-binary、固定HTTPS PyPI索引保证传递依赖缺锁和错误哈希实际失败，既有包不绕过锁；不执行sdist构建。SDK根依赖分离为rich/PyYAML/typer/platformdirs，其他业务依赖必须操作方明确锁定。

policy4/schema2 catalog与不可变image ID、base_reference、锁SHA256、当前SDK代码/资源SHA256及插件指纹绑定，执行时核对镜像label，旧policy或代码摘要不符拒绝并要求重新prepare。构建期间插件指纹改变不发布新catalog；catalog拒绝非普通/硬链接/超量文件及类型异常。source builder复用CLI，不再维护宽松路径或独立异常输出。SDK采用固定20文件库存，冻结版携带同一受限源码ZIP；不递归复制宿主模块。

真实临时wheel和pip验证hash/传递依赖拒绝；独立目标安装真实PyPI wheel（无索引安装、完整本地hash锁）后，Python -I -S在源码快照导入SDK/worker/egress并适配，未引入宿主site-packages。该原生证据仅Windows/Python3.12，不替代Linux镜像/多架构。哈希不是发布者签名或包无漏洞证明；锁审查、基础镜像可信来源、真实daemon构建/取消及恶意插件隔离仍须验收。

## 执行控制与协议错误边界（2026-10-13）

_control复用进程树capture，每次30秒/16KiB、stdin关闭；非零、OS/期限/输出错误均变为固定SandboxError，不附Docker原始日志或异常值。网络inspect只读Networks，验证IPv4字段并拒绝非地址/危险地址。保留自定义Docker地址池支持，不以RFC1918范围替代内部network隔离权威。

实际临时Python客户端及子进程证明静默超时/注入取消/超量回收；临时客户端还通过真实_invoke读取受控错误/坏协议，固定平台错误且不写插件状态，不导入测试插件哨兵。Docker API替身证明精确查询和自有proxy/network清理请求，不证明daemon资源确实不存在。主执行Popen树、整体预算、清理失败证据/恢复和真实daemon仍需验收。

运行时catalog去除无消费的dependencies字段；完整锁SHA256仍是执行权威。base_reference限4096字符，catalog读写共享16KiB上限，重复选择不放大记录。控制输出保护不等于任意插件业务stdout可被平台保证无秘密，业务stdout及网络授权仍由插件和操作方承担。

## 主执行客户端监督的本地证据

主执行已改用core.process.start：Unix进程组、Windows挂起后加入kill-on-close Job再运行。RPC回复写入在受监督线程进行，等待共用执行期限；静默客户端及不读取stdin的大回复客户端测试确认父子进程终止、管道关闭、状态不提交。无效timeout拒绝非有限/布尔/越界值。共享stream的读取线程启动失败也在资源清理范围内。

这只验证已知本地客户端；同步broker尚不能强制中断，快照/配置/状态保存也未纳入完整可中断总预算。rm失败仍缺持久恢复凭据，容器/网络实际不存在的daemon证据未建立。不得以本地Job/进程组终止代替容器清理或完整沙箱安全达标。

## 索引任务的待回滚状态与启动恢复

公开update reconcile验证已退出helper、绑定健康记录与完整备份后，对prepared且目标仍为新字节的回滚返回deferred/reason=rollback_pending，不替换程序。启动专属reconcile_on_boot在同一根/目标锁内重试原事务，复用transaction_id；成功恢复后优先请求重启，退役凭据失败保留索引，恢复失败保留prepared记录。该路径由30秒一次性worker监督，禁止不确定helper触发恢复。

本地真实PowerShell测试已验证临时字节文件的提交、中断回滚和原事务恢复。它不证明实际运行的冻结Windows程序可同步被替换；OS拒绝时保留待恢复记录，不回退直接覆盖。延迟回滚helper、原生产物的真实重启、无索引Unix恢复、完整旧任务和断电恢复仍需验收。

## wheel库存与独立安装发布检查

scripts/verify_wheel.py逐字节核对官方Python/YAML库存，拒绝重复、多余、缺失及过大wheel成员，核对发行身份、console_scripts和完整RECORD SHA256/大小。pyproject的package include收紧为官方包及其子包，避免core_local等同前缀包被收录。

scripts/verify_installed_cli.py在独立环境、源码目录之外调用已安装入口，核对main/core来源、全部平台帮助、只读JSON及参数/源码更新拒绝，验证不创建运行数据。plugin run的帮助属于插件，独立记录而不尝试将--help当平台帮助；此验收不会执行第三方插件。CI六组合已加入构建/库存/独立安装检查及验收JSON留存，尚未远端执行。

当前本地已完成独立PyPI wheel依赖解析、安装入口及24项运行依赖的已知漏洞查询；CycloneDX SBOM和完整版本库存位于忽略的cache/wheel-release-b7hu07we。查询未发现已知漏洞，不包括构建/审计工具、OS/基础镜像、未知漏洞或项目逻辑风险。没有调用自动修复或更改宿主依赖。

## MySQL Windows ZIP解压边界

手工拼接ZIP成员路径已迁移到core.archive.extract_zip，保持单层官方前缀删除。所有原始名称先拒绝绝对路径、父目录、Windows盘符/ADS，链接及特殊类型、配额和root一致性在任何payload写入前检查；strip不会隐藏原始恶意路径或跳过成员的危险类型。默认strip=0为现有RustDesk调用保持布局。该修复不代表全部软件驱动已统一安全解压，也不证明同账户宿主攻击、OS目录竞态、cmd路径转义或实际数据库安装事务已验收。

## 归档布局与解析前边界

ZIP当前在创建输出目录前分别检查原始与剥离后的完整布局，拒绝规范化重名、文件/目录及父路径冲突、类型与目录标记矛盾；Windows另拒绝大小写路径别名、尾随点/空格、设备名称和非法字符。已有输出文件或路径内链接拒绝，写文件采用xb；竞争文件不覆盖，失败/取消只清理本次已创建的当前文件。多个文件的整体失败回收仍由独占staging承担，共享提取器不删除用户整个目录。归档路径限UTF-8 4096字节和128层，不把元数据阶段的无界读取当成提取额度已覆盖。

标准tarfile.open在extract_tar之前读取扩展PAX头；此前64MiB声明会触发64MiB读取。当前官方安装、Debian内包、缓存校验及插件状态回传均使用core.archive_reader的只读open_tar/open_zip，原始声明在该读取之前拒绝。只有生成构建上下文/插件返回状态的tar写操作继续使用标准写入口；第三方插件在其隔离环境中自行管理归档，不导入宿主服务。

| 解析边界 | 当前限制与行为 |
|---|---|
| tar成员与内容 | 最多100000成员、2GiB声明载荷；每个成员在枚举中检查，不先无限getmembers。调用方可降低额度，不能扩大平台上限 |
| tar扩展元数据 | 单扩展头1MiB、总头数据64MiB；成员名称/链接名称/128字节基础开销及应用PAX字段合计计费64MiB。PAX每个头最多128条原始记录（重复字段也计数），先检查长度数字、范围、关键词/等号/换行及截断再交标准库构造字段；有效字典也最多128键。嵌套8层、头总数最多成员额度的3倍；所有GNU sparse形式及特殊类型拒绝 |
| 压缩tar | 原始/gzip/xz/bzip2；压缩输入和展开跨度各≤2GiB+256MiB，单次读取/解压块≤1MiB；XZ字典≤128MiB，单流/标准零填充，非法尾部拒绝 |
| 压缩缓存与提交 | gzip/xz/bzip2按需解压到私有临时文件，重复读取用磁盘缓存；成功离开上下文前验证剩余压缩尾部，校验失败不进入外层发布；失败/取消关闭并删除本次临时文件 |
| ZIP元数据 | 中央目录≤16MiB，先流读记录检查实际成员数与声明数一致再构造ZipInfo；单盘、≤100000成员、声明载荷≤2GiB，支持正常ZIP64及自解压前缀 |
| ZIP解码策略 | 仅无密码stored/deflated，拒绝BZIP2/LZMA及其他未提供安全解码预算的ZIP方法；明确报错，不回退旧入口。tar的xz/bzip2支持不受该ZIP策略影响 |
| 提取布局 | 显式成员和隐式父目录合计≤200000个不同路径，路径UTF-8字节加每节点128字节计费≤64MiB；ZIP同时计入大小写规范键与原拼写。先限额再创建目录图/输出；共享父目录只计一次，原始与剥离后ZIP布局分别检查 |
| 插件状态 | 沿用32MiB线路字符串、16MiB状态和4096成员；打开tar采用更小的载荷/成员/元数据额度，布局节点上限同步降至8192，字节计费≤16MiB；超额不替换旧状态 |

解析和布局额度是逻辑资源界限，不是进程RSS或硬实时保证。5万重复PAX字段在标准库解析前拒绝，隐式目录预算已覆盖tar、映射tar、ZIP及插件状态；真实Redis7.4.2包正常布局通过，但未执行/编译。仍需最旧Python版本/私有stdlib钩子兼容、特殊文件系统、多平台正式发行包及整次操作期限验收；压缩缓存带来额外临时磁盘占用，额度/磁盘满失败不能绕开事务恢复。来源核验、系统跨用户权限、后续环境/服务写事务和恶意插件完整生命周期仍是独立门槛。

## 原生插件基础验收

原生插件基础验收使用scripts/verify_plugin_native.py，必须提供审核过的--base-image（registry digest）、--lock-file、已安装--cli-entry和不存在的--output目录。脚本只生成并授权自己的合成插件，配置/插件目录/状态和宿主canary均隔离在输出目录；禁止将用户数据目录作为输出。先验证来源格式与原始锁路径（不解析掉链接），再构建。两个监督器调用及一次源码外已安装CLI路由验证参数、状态与基础隔离；原始证据留在输出目录。CLI示例：

```text
python scripts/verify_plugin_native.py --base-image IMAGE@sha256:DIGEST --lock-file REVIEWED.lock --cli-entry INSTALLED_OPSKIT --output NEW_TEST_DIRECTORY
```

占位值须替换为已审核的真实输入。镜像/构建缓存保留供审查，不对Docker执行全局prune；不清理其他用户资源。该检查观察cgroup/tmpfs额度及无网络权限，不能代替内存/PID耗尽、获批网络代理/RPC、执行中撤权、取消、daemon失败恢复、多架构与正式基础镜像漏洞/SBOM验收。

## 历史秘密门槛

本地Windows/Linux同版本已扫描所有本地引用及合并差异，当前提交候选文件也扫描过，未发现匹配；合成高熵PAT阳性已检出且报告/日志不含原值。连续字符样例被默认规则过滤，保留此失败对照说明规则边界。默认规则、二进制/嵌套编码、不可达对象及未拉取远端引用仍有覆盖局限；远端CI尚未执行，秘密不存在与完整生产安全均未据此证明。
