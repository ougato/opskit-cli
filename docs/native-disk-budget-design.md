# 原生插件空间检查与产物维护

框架仅配置 `plugin.disk.minimum_free_mib`，默认 2048MiB，范围 256..1048576MiB。`opskit plugin disk-policy --minimum-free-mib 2048` 查看或调整阈值。菜单位置：插件管理 → 插件维护 → 空间设置。

此值用于通用空间预检查和执行期间检查，不承诺硬配额。配置读取只校验通用阈值；旧业务输出目录、保留数量即使格式错误，也不阻断框架读取阈值。保存阈值保留原有业务字段。

产物由宿主创建独立目录，执行后由插件决定是否登记成功凭据。凭据按插件隔离，内容及目录身份由宿主核验；执行和清理共享资源锁。清理拒绝活动任务、未知目录、链接、变化内容、跨插件及保留保护中的记录。失败或中断输出不自动登记、不自动删除。

构建输出目录、历史展示和保留数量迁入独立业务插件；旧记录保留不动。详见 [SDK 3 迁移](sdk3-business-separation.md)。
