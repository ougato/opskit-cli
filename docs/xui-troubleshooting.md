# X-UI 节点限制与连接排查

OpsKit 新建的 VLESS Reality TCP 节点通过面板 API 设置客户端 `totalGB=0`、`expiryTime=0`，表示不限流量、永久有效；入站层级的流量和到期时间同样为 0。流量统计仍然保留。云服务商的带宽、流量计费不受这些设置影响。

旧版本在创建入站后直接更新面板数据库，将客户端设为 1 TiB 和 365 天。新版移除此行为，不再绕过面板修改运行中的数据库。更新 OpsKit 源码或程序本身不会修改已有节点；再次执行安装时会通过面板 API 更新 OpsKit 管理的同名入站和客户端。

## 重复安装与失败恢复

重复安装会识别 `opskit-vless-reality-tcp` 入站，保留客户端 UUID、Reality 私钥、公钥、short ID、已有目标站点配置及其他客户端；将该托管客户端和入站启用并解除流量、到期限制。已有客户端的流量统计不会清零。指定不同 VLESS 端口会更新原入站端口，需要重新导入导出的链接。

3x-ui 3.11 的入站更新接口会保留客户端字段和启用状态。OpsKit 分别调用客户端更新、入站启用接口，并回读配置确认生效；旧版客户端接口仅在新版接口返回 HTTP 404 时回退。明确的 API 拒绝立即报错，网络中断则重新列出入站后重试，避免响应丢失造成重复新增。

同名入站不唯一、端口或客户端标识属于其他入站、同名入站不是 VLESS Reality TCP 时会停止，不覆盖或删除其他配置。安装不保证在网络不可用、下载失败、权限不足或资源冲突时成功。

安装失败的待处理配置包含私钥，以 0600 权限保存。排查时不要公开其内容。旧版程序产生的待处理文件可以在备份后由管理员删除。

## 修正已经安装的节点

1. 登录自己的 3x-ui 面板，找到 `opskit-vless-reality-tcp` 入站，编辑对应客户端。
2. 启用客户端，将总流量设为 0（不限），清除到期日期，选择永久有效；同时确认入站已启用，其流量与到期时间也没有限制。
3. 通过面板保存配置并重启 Xray，使用面板重新导出的完整 VLESS 分享链接导入支持 Reality 和 `xtls-rprx-vision` 的客户端。

这些限制是服务端配置，不在 VLESS 链接里，编辑分享链接不能解除限制。不要直接修改正在运行的面板数据库。

## 本机检查与外网检查

安装完成前，OpsKit 会重试检查 x-ui 服务状态，以及面板、VLESS 的 TCP 监听；失败会停止并报告错误。依赖安装包含提供 `ss` 的 iproute 软件包。这只能证明本机启动状态，不能证明外网可达或 Reality 握手成功。

在服务器运行：

```bash
systemctl status x-ui --no-pager
ss -lntp
journalctl -u x-ui -n 80 --no-pager
```

确认 VLESS 的端口（默认 TCP 443）由 Xray 监听，且没有被 Nginx 等其他程序占用。检查云安全组和服务器防火墙允许客户端访问该 TCP 端口；面板端口能访问不代表 VLESS 端口可访问。不要通过关闭整个防火墙解决。

如果端口已可达仍无法连接，检查面板中的 Xray 错误日志及客户端握手日志，核对 UUID、Reality 公钥、short ID、SNI 和 flow 与服务端一致；Reality 的目标站点需从服务器可达并支持所需 TLS 握手。默认目标站点并不保证在所有服务器网络中都可用。

终端可能将长链接折行。优先用面板复制按钮或 `opskit xui links --output-file <新文件路径>` 导出，导入时确保链接没有空格或换行。该导出文件包含凭据，请妥善保存。分享排查日志前隐藏面板密码、UUID、分享链接及私钥。

## 回滚本次修复

生产变更前应备份 x-ui 数据库（使用 SQLite backup 接口取得一致快照）、OpsKit 状态文件和源码。若需恢复数据库，先停止 x-ui，恢复备份及其受限权限，再启动服务，避免数据库与面板内存不同步。恢复旧数据库会恢复旧配额和有效期，不会保留备份后新增的流量与配置。
